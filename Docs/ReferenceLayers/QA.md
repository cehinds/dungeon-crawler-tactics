# Reference layers QA

Status: accepted for exact stationary reference reconstruction and clean-environment switching. Independent checks pass; no runtime, Unity, or animation validation is claimed.

Run `python3 -m unittest Tools/test_reference_layers.py -v` from the repository root. The final six checks passed in 3.134 seconds. They independently alpha-compose exported PNGs and OpenRaster layers at native 1536×1024 offsets and painter order. Both compositions match the original reference with zero changed RGBA pixels. The source image is opened for comparison after composition and is never a visible draw layer. Comparison previews and cached group previews are separate from the component draw plan.

The original manifest contains 1,463 records: 1,317 visible fragment files and 146 fully occluded records without files. Every visible original fragment is independently rebuilt from its exported original-visible/context-restoration pieces; exact RGBA, source hash, bounds, anchor, offsets and nonoverlapping coverage are checked. The delivered inventory retains all original records. New context-restoration pieces carry explicit unassigned-context declarations: they restore source boundary pixels for the stationary exact view, and do not establish independently movable silhouettes or recovered hidden edges.

Disabling all non-clean layers reproduces the previously accepted map-grid-pass clean environment exactly. Inferred underpaint pixels are confined to its declared inferred-region mask. The original visible fragments preserve source pixels. Hidden floor, wall and background continuations remain generated interpretations. This package cannot establish what the occluded original artwork looked like.

Visual inspection covered the native reconstruction, native clean map, semantic exploded contact sheet, and a side-by-side original/reconstruction with a 128-pixel review grid. All reference positions, text, actors, targeting highlights, HUD, water outlets and architectural joins align. The clean map shows no actor, HUD, path, or targeting silhouettes. The context-restoration contact sheet intentionally contains source boundary/silhouette fragments; those pieces are explicitly grouped as exact-view context and excluded from clean mode. They must be handled together with their affected context before an object is moved.

Packaging checks verify every ZIP member against its on-disk bytes and package inventory SHA256, reject duplicate/traversal members, and validate ORA native offsets, group hierarchy and painter order. Original-reference and full-scene previews are comparison artifacts, not fallback layers. Geometry checks reject out-of-bounds crops, invalid anchors, unknown provenance and oversized reference-image draw fallbacks.
