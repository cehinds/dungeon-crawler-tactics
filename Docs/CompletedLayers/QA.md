# Completed module QA

The completed-layers package supplies complete inferred floor, water, architecture, pipes, props, blank HUD controls and overlay components. It does not recover the reference's hidden pixels or reproduce its original art exactly. The earlier 1,595 exact visible fragments remain separate and are not counted as complete objects.

The manifest records 315 assets: 144 reused authored map modules, 16 clean HUD backgrounds, 16 framed HUD controls, 24 new overlay designs, 95 derived construction regions, one whole exit object, 17 reference-placement object variants and two continuous water regions. The 95 construction regions are subdivisions of generated architecture, not 95 newly authored objects. Native overlay crops and normalized variants retain their shared source ancestry.

Run `python3 Tools/test_completed_layers.py`. Independent checks reconstruct the scene from individual PNG assets and native positions, reconstruct each of nine category plates, replay the editable OpenRaster instance stack and verify archive files against SHA-256 records. Preview images are comparison targets, never reconstruction inputs. The recipe contains 255 placements. Offsets locate image upper-left corners; pivots are image-local and include normalized values. Four-side sockets describe compatibility; collision boxes are illustrative placement metadata rather than tested gameplay collision.

The entire ground canvas is opaque. Both declared canal rectangles are opaque behind banks, pipes and props. Moving all non-surface instances by a fixed offset still exposes fully covered ground. Hiding any category leaves an independently reconstructable plate beneath it. This validates surface coverage; the visual review also checks wall silhouettes and intentional openings rather than trusting `occlusionHoles:false` metadata alone.

Visual review compared the original combat reference, the earlier partial architecture and the final reference-aligned scene. The completed architecture retains the reference's broad top, side and front wall footprint, with complete masonry around intentional floor, canal and doorway openings. The exit is a whole component. Pipes and props have independent silhouettes, the central prop is the red barrel, floor variation is restrained and blank HUD elements include their complete frames. The generated cyan cues have filled centers where the source actually supplied filled art. The layout and textures remain an interpretation; actors, text and animated water behavior are not established by this package.

A northwest baked pipe-cap remnant was found and removed. The final architecture-only view was inspected with pipes disabled; regression checks confirm the cleared cap area remains transparent over the complete canal. The gold exit was replaced with a newly generated isolated object, whose complete cornice, lamp, jambs and threshold have exterior margins before resizing; no arrow-shaped hole remains. Soft alpha in generated effects is intentional; translucent pixels are not treated as missing object areas.

Validation status: all six independent checks pass. OpenRaster contains 255 editable instance leaves in nine category groups and replays exactly, including soft alpha. All 5,538 prior pack files match the captured baseline. Two complete local rebuilds produced identical hashes for every package file, including ORA and ZIP; an extracted ZIP replay produced an exact pixel match to the composition preview. No Unity or gameplay integration test is claimed for this standalone art package.
