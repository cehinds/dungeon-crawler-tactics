# Reusable HUD QA

Validated the final export with `python Tools/test_reusable_hud.py`: **PASS**.

The delivery contains 205 reusable parts across 17 groups, plus 78 archived source fragments. It includes 16 reconstructed blank backgrounds, 112 border pieces (including one literal center residual), 33 raster glyph runs, six separately retained portrait-edge and stat-fill fringe overlays, two complete stat tracks, and 36 other icon, portrait, indicator, glow, separator and stat-cap/stretch parts.

Every clean background independently matches its authored exterior rectangle or polygon. Alpha is 255 throughout that shape and zero outside. A separate exterior flood-fill test confirms no enclosed transparent cutouts. This covers the full bottom dock, four party cards, selected portrait backing, objective, phase, four actions, target card, end-turn control and both stat backings. Both rebuilt stat tracks are fully opaque across their authored bounds. Blank HP and Mana controls also have complete opaque backing rectangles and explicitly pass a color check rejecting red/cyan fill contamination.

Each blank widget composes only clean background, border or stat structural assets; icons, portraits, glyph runs, selection glows and colored portrait-edge overlays are excluded. Every blank and repopulated widget matches an independent composition from exported PNGs, declared positions and layer order. Frame pieces and preserved fringe overlays rejoin their literal source frames and stat outlines exactly. Source crop and subset provenance checks ensure retained source pixels are unaltered. Group references, hierarchy, IDs, offsets, dimensions, PNG hashes, generated-material hashes, package-member hashes and byte lengths all pass. The OpenRaster layer stack independently recomposes the delivered full preview, and the ZIP matches every packaged file byte-for-byte.

Visual inspection of the overview and focused Move before/after confirms the new backgrounds have no boot, lettering, action-icon or portrait silhouettes. The bottom dock is a continuous clean navy surface. Blank party borders have had the visible purple/red/blue portrait fringes separated into foreground overlays. Blank HP and Mana show no colored fill line; the colored source-outline residuals are separate foreground overlays. The Move example clearly exposes blank material, blank framed control, original icon, original raster label, frame and glow independently.

The original `hud-components` directory remained unchanged: all 148 files matched the SHA256 snapshot taken before this build. All 78 originals copied into the reusable package also match their existing files byte-for-byte.

The reconstructed blank materials intentionally differ from the original screenshot. This validation establishes clean geometry, complete opacity and consistent exported compositions; it does not claim the reconstructed HUD is pixel-identical to the source. Text remains raster glyph runs rather than editable font objects. The original source fragments remain available for reference and exact original replay. Border rejoin is tested at native size; arbitrary stretched layouts have not been visually certified.
