# Alternative art styles

New style exploration requested after the initial overhaul concepts. These are
unmodified generated concept images, not implemented gameplay or final assets.
All three show a rescue encounter with Carl, Donut, Katia and Mongo.

Displayed order in this ideation set:

1. [Pocket Dungeon](https://github.com/cehinds/AI-Art/blob/dungeon-crawler/dungeon-crawler-tactics/Docs/ConceptArt/Styles/pocket-dungeon.png): overhead handheld pixel art, cream/plum interface, square tiles.
2. [Ink & Lanterns](https://github.com/cehinds/AI-Art/blob/dungeon-crawler/dungeon-crawler-tactics/Docs/ConceptArt/Styles/ink-and-lanterns.png): painted gouache/ink world, soft materials, parchment interface.
3. [Dungeon After Dark](https://github.com/cehinds/AI-Art/blob/dungeon-crawler/dungeon-crawler-tactics/Docs/ConceptArt/Styles/dungeon-after-dark.png): graphic-novel ink, halftone shadows, cyan/coral/yellow spectacle.

This set supersedes the earlier numbered concept options for any subsequent
numeric selection. No style is selected yet. Original generations remain in
/workspace/generated_images. Generated icon shapes and layout geometry still
need production review before asset extraction or implementation.
