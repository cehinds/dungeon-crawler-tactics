# Exploration component QA

This pack separates exact contextual reference crops, exact visible surface patches, and generated complete-object reconstructions. A contextual crop may contain neighboring pixels or an occluded object; it is evidence, not a reusable whole object. Generated reconstructions are approximate alternate artwork, not pixel-perfect recovery of hidden source pixels.

Independent verification lives in `Tools/test_exploration_components.py`. It checks exact decoded RGBA and dimensions for every declared source crop and every reused dependency; reruns the declared canonical scan to detect both false reuse and missed exact matches; checks category counts and transparency; independently renders the JSON recipe from individual components; measures remaining visible floor; and verifies archive closure and byte identity. The replay uses the surface patch and component IDs, without loading the reference image or a precomposed scene.

A session baseline at `/tmp/exploration-components-prior-hashes.json` records SHA256 for all 27,925 preexisting asset files, including wall-components. The preservation check uses that baseline when present and explicitly skips it in a fresh checkout where the session baseline is unavailable. It does not imply a persistent cross-check against an absent baseline.

The 64-object build passed all six independent test methods (34.632 seconds). Inventory: 126 uniquely identified components: 64 generated reconstructions, 57 exact contextual reference crops, and five exact visible surface patches. A separate scan of 16,382 eligible canonical PNGs found zero exact matches; zero reused assets is therefore supported by dimensions and decoded RGBA, rather than visual similarity. Generated reconstructions and exact source evidence are counted separately; no extra normalization-derived files are counted as new artwork.

Visual review covered the reference, all five generation sources, all nine category contact sheets, the complete-object exploded plate, and the furnished preview. It caught and corrected a duplicate training-dummy ID, out-of-canvas preview placements, and a barrel corner in the forge floor patch. All 64 solid silhouettes have complete outlines in the reviewed exports; intentional portrait baselines and transparent door openings are part of the artwork. Each generated export adds eight pixels of genuinely transparent padding. Source masks and preserved crop pixels are checked independently. Solid silhouette boundaries use alpha ≥128; faint generated glow can be truncated at hand-selected extraction boundaries and is explicitly disclosed in provenance. This does not claim mathematical recovery of every glow pixel.

The primary preview furnishes four approximate functional quadrants around a corridor with party sprites and HUD pieces. Its architecture is partial, its source-derived floor repeats visibly, and it is not a clone of the concept scene. JSON replay reproduces the exported preview exactly; that equality is between recipe replay and its preview, not between preview and reference. It uses individual component IDs and source-visible surface patches. Floor covers over 75% of the canvas before furnishings, with over 35% still visible afterward.

A faint line beneath the gear icon was identified as neighboring frame glow. A fifth generation source supplies a clean standalone bag replacement. Its full silhouette was independently reviewed with no neighboring frame pixels. The exported replacement and refreshed UI plate were reviewed clean. Final verification passed all six checks, including all 64 normalized 128×128 variants and package member sizes/hashes. The standalone replacement preserves the total of 64 reconstructions.
