# Map grid pack publication

The complete `map-grid-pass` research and asset package is indexed and published in AI-Art on the `dungeon-crawler` branch. Use the exact revision pinned by `art-assets.lock.json` for immutable downloads, including comparison sheets, generated source atlases, extracted components, layered environment reconstruction and ZIP delivery.

This pack is an offline download and review deliverable. It is not integrated into the playable runtime. The Pages artifact excludes only `assets/map-grid-pass/` through the shared pre-copy and final-prune policy, keeping the deployment below its 1 GB limit. Canonical source files, ZIP members and AI-Art index records remain complete; other runtime asset folders retain their existing publication policy.
