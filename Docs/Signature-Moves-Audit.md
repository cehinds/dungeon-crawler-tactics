# Signature moves audit (Books 1–4 / playable Floors 1–8)

This audit answers a narrow question: do the deployed characters have recognizable, source-grounded moves in the current tactics data? Canon entries below are supported by the publisher's authorized Book 2 sample where possible and by the DCC Database for granular ability names and timing. Database pages are secondary references and include later-book material; this audit uses only early examples and stops plot detail at Book 4. No canonical ranks or numerical combat effects are inferred.

## Initial audit snapshot (2026-10-23, before the signature-moves pass)

This is the state captured before the work described in the dated update below. The main party in `UnityPackage/Runtime/Data/game-content.json` starts with Carl, Princess Donut, Katia, and Mongo selected and deployed. Their innate IDs were `ability.carl_powerful_strike` / `ability.carl_bomb`; `ability.donut_magic_missile`, `ability.donut_puddle_jumper`, `ability.donut_heal_critter`; `ability.katia_shapeshift`, `ability.katia_heavy_blow`, `ability.katia_new_look`; and `ability.mongo_bite` / `ability.mongo_pounce`. Additional bespoke moves appeared in class trees/catalog data, but were not all immediately available. Elle, Imani, Louis, and Britney were deployable roster reserves with only generic `ability.strike` as a personal innate action; their class kits were catalog content and class abilities could supply further moves after selection.

## Reserves and catalog-only content

The roster has four additional deployable crawlers (Elle, Imani, Louis, Britney) whose innate actions are generic Strike. They are selectable/deployable in the game, but their distinctive personal skill identities are not represented by those innate IDs. Their class catalogs should not be counted as signature character moves: a class action can be source-attested without being a character's personal iconic ability. Mordecai is in the roster but `deployable: false` and is described in the README as the camp advisor; this makes his battle abilities catalog-only in the current party flow. Carl/Donut/Katia/Mongo's tree-only upgrades should likewise be called out as unlockable, not currently equipped, when discussing the opening loadout.

## Initial audit ranking (pre-pass)

1. **Donut: Character Actor / floor specialty choice.** This most directly expresses the unusual class and changing character identity. The Book 3 sample anchors a new class choice at floor transitions, with a timer and random fallback; a curated floor-gated specialty system would be an adaptation of the selection, not a canon list of turn actions.
2. **Donut: Hole or Clockwork Triplicate.** Hole is a named, source-grounded environmental control spell; Clockwork Triplicate is a named pet/minion duplicate spell. They give her immediately recognizable tactical identity missing from the current kit. Do not invent canonical rank values or broaden Triplicate's target eligibility.
3. **Katia: momentum/Rush action.** Existing forms cover the silhouette; a charge that rewards line/space/momentum would make Monster Truck Driver's combat identity legible. Any grid effect is invented.
4. **Carl: trap setup.** His current bomb ignites a tile; it does not deal direct blast damage. A place/arm/trigger trap loop better expresses Compensated Anarchist's explicit class identity. Treat trap behavior as adaptation.
5. **Mongo: role correction or visible adaptation label.** Current deployment as a fourth crawler is a larger fidelity decision than tuning bite damage. Treat the companion as pet/summon support if the roster model permits, or label the four-unit party slot as a deliberate adaptation.
6. **Other deployable reserves: personal moves.** Replace generic Strike-only innate kits with one sourced or explicitly adapted signature per character before presenting the reserve roster as individually characterized.

## Signature-moves pass status (2026-10-23)

This section records the implementation present in the shared data/core files after the initial audit. The added combat values and target rules are game adaptations; the books do not define these turn-based numbers.

- [x] **Carl — trap setup and explosives.** The personal kit now includes `ability.carl_tripwire` (Rig Shock Tripwire). Progression adds `ability.carl_dynamite` at party level 2 and `ability.carl_freeze_trap` at level 3. Their range, cost, entry effects, and level gates are game data, not canon ranks or exact novel mechanics. Existing `ability.carl_bomb` remains a tile ignition action (it adds Burning and has no immediate damage); it is not a direct blast. Canon supports explosives and trap-making as a Compensated Anarchist theme, but these named tactics are adaptations.
- [x] **Donut — Character Actor and Clockwork Triplicate.** In story mode, the safe-room specialty choice becomes available from Floor 3, once each floor. It adds a curated temporary class kit for that floor while preserving Donut's permanent class. The available Stormcaller, Cryomancer, and Cleric kits are game-authored choices; the novels do not establish this curated list or these exact combat rules. `ability.donut_clockwork_triplicate` unlocks from Floor 3 at party level 3 and creates two controllable copies of an allied pet. The current game assigns the copies 12 HP, 3 movement, the pet's free attacks, and a two-round duration, with one pair per caster and no recursive copying. These values, control scheme, and restricted targeting are explicit adaptations of the canon spell's pet/minion duplication role.
- [x] **Katia — Rush.** `ability.katia_rush` unlocks from Floor 3 at party level 3, costs 3 Mana, and adds two movement for two rounds. This represents the canon-named Rush skill as a tactics action; its Mana cost, movement bonus, duration, and trigger are adaptations, not canon spell values. It does not change her mass or copy another creature's powers.
- [ ] **Donut — Hole.** This remains deferred. Canon source and timing are documented above; no game ability is currently listed in her personal innate kit for it.
- [ ] **Donut — Puddle Jumper timing.** The spell remains in her initial personal kit even though the lore anchor places it as a reward after the Juicer during Floor 1. The current opening availability is a progression compression/adaptation.
- [x] **Core validation.** 32 focused signature checks and 84 full-route journey checks pass, including actual copy attacks, lifespan, deterministic save/reload, malformed-save rejection, specialty reset and Rush movement. The full shared-core suite totals 634 checks; 85 Python checks also pass.
- [x] **Browser validation.** `Tools/playtest_signatures.py` plays legally to Floor 3, reviews/cancels/commits a specialty, casts Triplicate on Mongo through the visible controls, inspects and moves a copy, ends its turn, and reloads the exact saved state. Desktop and phone captures show six party controls. Carl's Tripwire preview/cancel/commit is exercised through the actual action button and map. No JavaScript errors were reported.
